1. 等待动画案例

1.1 本节目标

完成本节后，你要能够：

  1. 用旋转表示“正在处理”。
  2. 用透明度呼吸降低视觉压迫。
  3. 用点提示形成节奏。
  4. 正确停止永久重复动画。
  5. 重置所有动画属性。

1.2 等待动画为什么不能只转圈

只旋转的圆环可以表达“忙碌”，但很容易产生两个问题：

因此实际等待动画常组合三类变化：

圆环 RotateTransform.Angle 表示持续处理
整体透明度 Opacity 呼吸，降低机械感
三个点 依次变化的透明度 形成节奏

1.7 跟做检查点

  • [ ] 圆环持续旋转。
  • [ ] 圆环透明度有轻微呼吸。
  • [ ] 三个点不是同时亮灭。
  • [ ] 停止后旋转角度归零。
  • [ ] 停止后透明度和点都恢复。

1.8 常见错误

现象 常见原因 修正方法
越转越快 重复创建 Forever 动画 开始前先停止旧 Storyboard
停止后仍在闪 只停止了部分子动画 用一个 Storyboard 管理
旋转中心不对 没有设置 RenderTransformOrigin 设为 0.5,0.5
等待动画太抢眼 颜色过深、速度过快 降低对比度、延长时间
停止后透明度残留 没有恢复 Opacity 停止后显式设置基础值
页面关闭后还在运行 没有处理窗口关闭 关闭时停止动画

1.9 小练习

  1. 把旋转一圈改成 1.4 秒。
  2. 把点的延迟间隔改成 0.22 秒。
  3. 给文字增加轻微的透明度呼吸。
  4. 把圆环颜色改成绿色。
  5. 在窗口关闭时停止等待动画。

2. 多轴机械臂动画案例

2.1 本节目标

完成本节后，你要能够：

  1. 用嵌套布局建立机械臂层级。
  2. 给每一节设置正确的旋转中心。
  3. 让多个关节同时执行不同角度的动画。
  4. 理解父级旋转会带着子级运动。
  5. 能排查子节位置异常。

2.2 为什么机械臂不能只做四个独立旋转

机械臂不是四个互不相关的图形：

图 3：机械臂的旋转层级和各自的旋转中心。

层级关系：

如果肩部旋转时，肘部没有放在肩部内部，肘部就不会跟着肩部一起动。

2.3 RenderTransformOrigin 为什么重要

每个关节必须绕连接点旋转，而不是绕自身中心随便转。

层级 旋转中心 原因
底座 0.5, 0.95 接近地面连接点
肩部 0.5, 1.0 绕肩关节底部
肘部 0.5, 0.1 绕肘关节顶部
夹爪 0.5, 0.5 绕自身中心

2.8 跟做检查点

  • [ ] 底座旋转时整条机械臂跟着转。
  • [ ] 肩部旋转时肘部和夹爪跟着动。
  • [ ] 每个关节绕连接点旋转。
  • [ ] 四个关节的结束角度不同。
  • [ ] 复位后所有角度归零。
  • [ ] 能说清父子层级关系。

2.9 常见错误

现象 常见原因 修正方法
子节没有跟着动 子节没有放在父节内部 检查嵌套层级
关节像绕着中心乱转 旋转中心设置错误 检查 RenderTransformOrigin
机械臂飞离底座 父级变换叠加异常 从最外层逐层排查
所有关节同时停 Duration 相同 分别设置时长
复位后仍有偏移 只重置了部分关节 重置四个角度
动画叠加 播放前没有停止旧 Storyboard 先 Stop

2.10 小练习

  1. 把肩部结束角度改成 -72°。
  2. 把夹爪动画改成 AutoReverse=true。
  3. 让肘部先动、肩部后动。
  4. 增加一个“抓取并返回”的组合动画。
  5. 在日志中显示每个关节的当前角度。

3. 蚂蚁线动画案例

3.1 本节目标

完成本节后，你要能够：

  1. 使用 StrokeDashArray 创建虚线。
  2. 使用 StrokeDashOffset 让虚线流动。
  3. 控制蚂蚁线方向。
  4. 区分“路径移动”和“虚线偏移”。
  5. 停止后恢复虚线偏移。

3.2 蚂蚁线到底是什么

蚂蚁线不是移动整条路径，而是改变虚线的起点：

图 4：路径不变，虚线偏移持续变化。

3.3 StrokeDashArray 与 StrokeDashOffset

属性 作用
StrokeDashArray 定义虚线段与间隔
StrokeDashOffset 定义虚线从哪里开始
StrokeThickness 定义线的粗细

如果虚线数组是：

可以理解为“线段长、间隔短”。数组中的数字按线宽比例计算。

3.8 跟做检查点

  • [ ] 路径本身不移动。
  • [ ] 虚线持续向前流动。
  • [ ] 反向按钮能改变流动方向。
  • [ ] 停止后虚线偏移恢复为 0。
  • [ ] 能区分虚线数组和虚线偏移。
  • [ ] 重复开始不会叠加时钟。

3.9 常见错误

现象 常见原因 修正方法
看不到虚线 没有设置 StrokeDashArray 设置数组
虚线太密或太稀 数组比例不合适 调整线段和间隔
没有流动 偏移量没有变化 动画 StrokeDashOffset
方向相反 偏移正负号相反 交换方向
停止后偏移不归零 没有移除动画并重置 设置偏移为 0
重复播放变快 旧时钟未停止 先 Stop

3.10 小练习

  1. 把虚线数组改成 3 2。
  2. 把动画时长改成 1.2 秒。
  3. 把路径改成闭合矩形。
  4. 给虚线增加圆角端点。
  5. 让蚂蚁线只在选中时播放。

综合练习

练习一：等待卡片

要求：

  1. 圆环旋转。
  2. 文字透明度呼吸。
  3. 三个点依次变化。
  4. 停止后全部恢复。
  5. 窗口关闭时释放动画。

练习二：四轴机械臂

要求：

  1. 建立四级嵌套。
  2. 每级旋转中心正确。
  3. 四个关节时长不同。
  4. 支持抓取和复位。
  5. 记录每个关节角度。

练习三：闭合蚂蚁线

要求：

  1. 使用闭合路径。
  2. 虚线沿路径流动。
  3. 支持正反方向。
  4. 停止后偏移归零。
  5. 与选中状态联动。

练习四：三层溶液波浪

要求：

  1. 三层不同相位。
  2. 三层不同透明度。
  3. 液位可配置。
  4. 振幅可配置。
  5. 启动和停止都只创建一个时钟。

练习五：波浪控件类库

要求：

  1. 新建 WPF 类库。
  2. 把 LiquidWaveControl 移入类库。
  3. 增加 BubbleCount 依赖属性。
  4. 增加 IsAnimating 只读依赖属性。
  5. 在主项目中引用并使用。
