CSharp数据类型的认识

发表于2026-09-02|更新于2026-09-02|CSharp
|字数总计:2.8k|阅读时长:10分钟|阅读量:

零、先问个问题：数据类型是个啥？

打个比方：你要往一个杯子里装东西，杯子有很多种——水杯（装水）、酒杯（装酒）、汤碗（装汤）。数据类型就是「装数据的杯子」，你得先告诉电脑你要用哪种杯子，它才知道怎么帮你装、怎么帮你用。

C# 自带了一堆「杯子」，每种能装的东西不一样大、不一样精确。我们这一篇先把表格里那 11 种类型一个一个过一遍。

本次目标只有一句话：看到一种类型，能说出来——它叫什么、能装多大、是整数还是小数、经常用在哪。

一、整型家族：byte 和 sbyte（最小的一对兄弟）

表格里第一对是 Byte 和 SByte，它们的区别就一个字母 S：S 代表 Signed（有符号），没有 S 代表 Unsigned（无符号）。

类型 名字 范围 占用空间
sbyte 有符号字节 -128 到 127 1 字节
byte 无符号字节 0 到 255 1 字节
怎么理解「有符号 / 无符号」？

想象成一块路牌：

  • 无符号（byte）只能往前数：从 0 开始，数到 255。
  • 有符号（sbyte）有个 0 路口，左边是负数（-128 ~ -1），右边是正数（1 ~ 127），0 自己站路口。

所以同样是「1 个字节（8 位）」，byte 能装 0 ~ 255，sbyte 把一半空间让给了负数，就只能装 -128 ~ 127。

能跑起来的小例子

在 Visual Studio 里按 Ctrl + F5 跑一下，看到黑窗口里打出「温度：-10」「阀开度：200」就对了。

上位机里啥时候用？
  • Modbus RTU 里读取单个寄存器的「字节」，经常先落到 byte。
  • 串口报文里每一帧的字节，也用 byte 数组装。
  • 温度、压力这种可以负的量，会用 sbyte 或更「胖」的类型（往下看）。

二、再胖一点：short 和 ushort

跟 byte / sbyte 是一模一样的关系，就是「杯子」变成了 2 字节大小。

类型 名字 范围 占用空间
short 有符号短整型 -32768 到 32767 2 字节
ushort 无符号短整型 0 到 65535 2 字节

上位机里啥时候用？

有些老 PLC（比如西门子 S7-200）单个模拟量通道就是 16 位（2 字节）整数，读上来用 short 接刚刚好。

三、最常用的主力：int 和 uint

重点来了，绝大多数情况下你写代码用的整数就是 int。

类型 名字 范围 占用空间
int 有符号整型 -2147483648 到 2147483647（约 ±21 亿） 4 字节
uint 无符号整型 0 到 4294967295（约 42 亿） 4 字节

例子

注意原表里 Int 写的是「-2E31 ~ 2E31-1」，那是科学计数法的简写，意思就是 -2^31 ~ 2^31-1（差不多 ±21 亿）。后面 Long、UInt 也是同样的写法。

上位机里为啥这么常用？
  • Modbus TCP 读保持寄存器，返回的就是 16 位整数，乘个系数后再放进 int。
  • 计件数、扫码枪的物料编号、生产班次号……基本上都是 int。
  • 如果确认不会为负，用 uint 表达更清楚（别人一看就知道「这玩意儿不会小于 0」）。

四、最大块的：long 和 ulong

long 是「加大版整数」，能装非常大的数。

类型 名字 范围 占用空间
long 有符号长整型 -9223372036854775808 到 9223372036854775807 8 字节
ulong 无符号长整型 0 到 18446744073709551615 8 字节

例子

看代码里数字后面那个 L / UL 没？没加的话，C# 默认按 int / uint 处理，数字一大就报错。加个 L 就是告诉电脑：「这哥们其实是 long / ulong，别搞错了」。

上位机里啥时候用？
  • 时间戳：从 PLC 上来的「开机总时间」、服务器下发的「UTC 时间戳」都是 long。
  • 累计流量：工厂一年的水流量、电量，用 int 可能装不下，必须 long。
  • 序列号 / 流水号：超过 21 亿的千万别用 int，会绕回负数。

五、带小数点的「浮点型」：float

整数只能装 1、2、3 这种干干净净的数，带小数的就得用浮点型了。

类型 范围（大约） 占用空间 精度
float ±3.4 × 10^38 4 字节 大约 6~7 位有效数字
double ±1.79 × 10^308 8 字节 大约 15~16 位有效数字

第一个浮点类型：float

float 一定要在数字后面加 F 或 f，比如 36.5F。这是 C# 的规矩，不加 F 它就以为你是 double，往 float 里塞 double 会报错。

六、常用主力浮点：double

类型 范围（大约） 占用空间 精度
double ±1.79 × 10^308 8 字节 大约 15~16 位有效数字

例子

七、不是数字：对和错——bool

「布尔类型」就两个值：真（true）、假（false），不用纠结范围。

类型 取值 占用空间
bool true 或 false 1 字节

例子

上位机里啥时候用？
  • 心跳信号：设备是不是还活着？
  • 报警标志：温度超标了没有？
  • 阀门状态：开/关。
  • 通信结果：读寄存器成功了吗？

基本上所有「是不是 / 有没有 / 成功了没」的问题，答案都是 bool。

八、文本家族：char 和 string

char 是单个字符，string 是一串字符。

类型 含义 例子
char 单个字符，用单引号 'A'、'你'、'1'
string 一串字符，用双引号 "Hello"、"设备1号"

例子

注意看引号：char 用单引号（'A'），string 用双引号（"A"）。写错引号会编译报错。

上位机里啥时候用？
  • 设备名称、点位编号："PT-101"（压力变送器 101）。
  • 通信报文：Modbus、串口协议返回的字节，经常需要先转成 string 才看得懂。
  • 报警消息：拼接 "温度超限！" + 当前值 + "度" 直接显示到界面上。

十二、小结

这一篇我们学了 12 种 C# 常用基础类型：

  • 整型家族（byte / sbyte / short / ushort / int / uint / long / ulong）：装整数，越往后越大。
  • 浮点家族（float / double）：装带小数点的数，double 更常用、更精确。
  • bool：装真 / 假。
  • char / string：装字符和文本。

记一个简单口诀：

有 S 能负数，没 S 全正数；小数看 F 字母，文本看双引号。

  1. 在 Visual Studio 里把上面那段代码改一改——比如把 double 改成 float，看会报什么错。
  2. 试着把表里每一种类型都用一遍，每个类型随便赋值、打印一次。
  3. 接下来我们会学变量——怎么给数据起名字，怎么改值。
