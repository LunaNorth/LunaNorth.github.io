属性 含义

1.6 EasingFunction 让速度更自然

线性变化从开始到结束速度一致。加入缓动后，速度可以发生变化：

模式 特点

EaseOut 开始快，后面慢

淡入使用 EaseInOut 比较自然。按钮回弹通常使用 EaseOut。

Margin 属于布局属性。连续修改它，布局系统可能需要重新：

2.11 位移和命中测试

RenderTransform 会改变元素的显示位置，也会影响 WPF 的命中测试转换。一般情况下，鼠标点击视觉上看到的位置是有效的。

但是，业务代码读取布局位置时仍然得到原来的值。例如读取 Canvas.Left，它不会自动加上变换偏移。

需要同时保存“逻辑位置”和“视觉偏移”时，要明确分别维护，避免混用。

4.3 KeyTime 是什么

KeyTime 表示关键帧到达的时间点，不是持续时长。

它表示“在动画开始后的第 800 毫秒，到达这个关键帧的值”。

重置后颜色不是蓝色 没有恢复基础颜色 显式设置颜色

6.1 本节目标

完成本节后，你要能够：

  1. 创建 SplineDoubleKeyFrame。
  2. 使用 KeySpline 控制关键帧之间的速度。
  3. 理解控制点对加速和减速的影响。
  4. 比较样条关键帧和缓动函数。
  5. 完成一个非线性速度的位移动画。

6.2 样条关键帧改变的是速度

样条关键帧仍然连续插值，不会跳变。它改变的是两个关键帧之间的速度曲线。

它们描述贝塞尔曲线的两个控制点。初学阶段不需要先推导数学，可以先观察四种常见组合的视觉差异。

6.3 常见 KeySpline 组合

组合 感觉

0,1,1,0 快速启动、快速收尾，中间有明显加速
0.2,0.8,0.2,1 起步较慢，后段逐渐加速

6.8 KeySpline 与 EasingFunction 的关系

两者都能改变速度，但位置不同：

机制 作用位置
EasingFunction 作用于单个动画或关键帧的缓动
KeySpline 作用于关键帧之间的插值

在关键帧动画中，KeySpline 是控制每一段速度最直接的方式。

6.9 怎样观察速度差异

仅看一次播放可能不够明显。可以：

  1. 把时长设为 3000ms。
  2. 在 500ms、1000ms、1500ms 三个时刻截图。
  3. 比较卡片在同一时间间隔内移动的距离。
  4. 改变 KeySpline，重复观察。

同样时间间隔内移动距离不同，说明速度不同。

6.10 跟做检查点

  • [ ] 动画包含至少两个 SplineDoubleKeyFrame。
  • [ ] 两个关键帧都设置了 KeySpline。
  • [ ] 卡片移动连续，没有跳变。
  • [ ] 速度明显不是简单匀速。
  • [ ] 暂停和继续都有效。
  • [ ] 重置后回到 X=0。
  • [ ] 能说出 KeySpline 和 EasingFunction 的区别。

6.11 常见错误

现象 常见原因 修正方法
看起来和线性一样 KeySpline 接近线性 使用对比明显的控制点
动画跳变 使用了离散关键帧 改为 SplineDoubleKeyFrame
速度变化不明显 动画太短 加长时长再观察
所有关键帧速度相同 只给部分关键帧设置 KeySpline 检查每个关键帧
暂停后位置跳回 重置了基础值或错误时钟 检查暂停逻辑
修改后没变化 修改的是旧 Storyboard 重新创建并开始动画

综合练习

练习一：做一个登录反馈动画

要求：

  1. 点击登录后按钮颜色变化。
  2. 按钮透明度短暂降低。
  3. 登录成功后显示一个绿色卡片。
  4. 所有动画统一由一个 Storyboard 管理。
  5. 失败时立即停止动画并恢复原状。

练习二：做一个通知卡片进入动画

要求：

  1. 卡片从右侧移入。
  2. 使用 TranslateTransform，不要修改 Margin。
  3. 使用样条关键帧让进入速度自然。
  4. 同时播放透明度变化。
  5. 动画完成后保持最终位置。

练习三：做一个状态指示器

要求：

  1. 使用离散颜色关键帧。
  2. 状态依次为“离线、连接中、在线”。
  3. 每个状态至少持续一秒。
  4. 暂停时状态保持。
  5. 重置后回到离线状态。

练习四：比较三种关键帧

要求：

  1. 三个卡片使用相同的时间点和目标值。
  2. 分别使用线性、离散、样条关键帧。
  3. 同时开始播放。
  4. 在同一时刻截图比较位置。
  5. 写出三种方式适合的真实场景。
