CSharp数值类型的自动转换和强制转换

发表于2026-09-03|更新于2026-09-03|CSharp
|字数总计:1.7k|阅读时长:5分钟|阅读量:

类型转换就是把一种类型的数据，变成另一种类型。

上位机里这种需求天天有：PLC 读上来的原始值常常是 int，换算工程量要用 double，算完又要显示成文字给操作员看。这一路就得不断做类型转换。这篇就讲两种转换：自动转换和强制转换。

本篇目标：分清「自动转换」和「强制转换」什么时候发生、会不会丢数据，能自己写转换代码，知道两个最容易踩的坑。

一、先打个比方：大杯子和杯子

记住这个比喻，整篇都靠它。

想象两个杯子：

  • 小杯子倒进 大杯子：水不会洒，安全，随便倒。
  • 大杯子倒进 小杯子：水会溢出来，你得自己小心，还可能洒掉。

类型转换一模一样。范围小的类型（比如 byte）转成范围大的类型（比如 int），就像小杯子倒大杯子，安全；反过来范围大的转范围小的，就像大杯子倒小杯子，可能丢数据。

二、自动转换（隐式转换）

自动转换就是「小转大」，电脑自动帮你完成，不用写任何东西，也不会丢数据。

自动转换的方向是「小到大、整数到小数」。判断标准就一条：目标类型能不能完整装下原来的值。装得下就自动转。

三、强制转换（显式转换）

强制转换就是「大转小」，电脑不帮你，必须你自己写代码，而且可能丢数据。

强制转换的写法：在值前面加括号和类型。

看清楚：小数是怎么丢的

25.6 转成 int 后变成了 25，小数点后的 0.6 被直接砍掉了，不是四舍五入。这就是「强制转换会丢数据」的意思——大杯子倒小杯子，水洒出来一部分。

强制转换的语法是 (目标类型)值，比如 (int)d。括号里写你想转成的类型。

四、一张表记住谁能自动转

自动转换有个固定方向，从范围小的一直往范围大的走。下面这张表从下往上，就是自动转换的方向。

类型 范围
double 最大，带小数
float 带小数，比 double 小
long 大整数
int 整数
short 小整数
byte 最小整数

记两个关键结论：

  • 整数之间，范围小的能自动转范围大的：byte 到 short、int、long。
  • 整数能自动转浮点：int 可以自动转 float、double。
  • 反过来，double 转 int、long 转 int，都必须强制转换，还可能丢数据。

doublefloat不能，要强制

一句话：小的能自动变大的，大的变小的必须强制。

五、强制转换的两个坑

强制转换最怕两件事：丢小数、溢出。下面分别看。

坑一：丢小数

36.9 转成 int 变成 36，小数被砍掉，不是四舍五入。上位机里温度、压力这种数据如果随便强制转 int，精度就丢了。

坑二：溢出

300 转成 byte 后变成了 44，因为 byte 只能装 0 到 255，300 超了，数字被「绕」回去了。这就是溢出。所以大转小之前，一定要想清楚目标类型能不能装下。

为什么 300 会变成 44

byte 只有 8 位，最大装 255。300 比 255 大了 45，多出来的部分从 0 开始重新数，就得到了 44。这个「绕圈」现象叫溢出，新手很容易踩，务必记住：大转小，先想清楚装不装得下。

七、小结

这一篇我们搞懂了两种类型转换：

  • 自动转换（隐式）：小转大、整数转小数，电脑自动完成，安全不丢数据。
  • 强制转换（显式）：大转小，必须自己写（类型）值，可能丢小数、可能溢出。

口诀：

小转大，自动跑；大转小，要强制，当心丢数和溢出。
