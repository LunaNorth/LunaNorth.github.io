CSharp运算符之位逻辑条件

发表于2026-09-02|更新于2026-09-02|CSharp
|字数总计:2.3k|阅读时长:8分钟|阅读量:

运算符就是让数据之间发生关系的符号。这一篇讲三类：逻辑运算符（判断真假）、条件运算符（一句话二选一）、位运算符（直接摆弄二进制位）。其中位运算在上位机里特别常用，比如读 PLC 一个字节里的开关状态。

本篇目标：会用 &&、||、! 做判断，会用 ?: 做二选一，会用 &、|、<<、>> 做位操作，能读懂「读一个字节里的 8 个开关」这种经典代码。

零、先分清三类运算符

类别 符号 作用 结果类型
逻辑运算符 && ` `! 判断真假 bool
条件运算符 ?: 二选一取值 看情况
位运算符 & ` `^ ~ << >> 直接操作二进制位 整数
逻辑运算符 和 条件运算符 是「判断」，位运算符 是「摆弄二进制」。下面一个个来。 --- ## 一、逻辑运算符：判断真假 逻辑运算符的答案只有两个：真（true）或假（false）。它用来回答「是不是、有没有、满不满足条件」这类问题。

三个符号先记牢：

  • 与（&&）：两边都为真，结果才为真。像「两个条件都要满足」。
  • 或（||）：两边只要有一个为真，结果就为真。像「两个条件满足一个就行」。
  • 非（!）：取反，真变假，假变真。像「反过来」。

上面代码里 temp > 80.0 这种比较，结果就是 bool 类型。再用 &&、||、! 把它们组合起来，就得到更复杂的判断。

用真值表记清楚

假设 A 和 B 是两个 bool 值，组合结果如下：

ABA 与 BA 或 B非 A
真真真真假
真假假真假
假真假真真
假假假假真

看「与」这一列：只有两个都真，结果才真。「或」这一列：只要有一个真，结果就真。

逻辑运算符两侧通常是比较式，比如 temp > 80，而不是直接写数字。写 80 && 100 是没意义的。

二、条件运算符：一句话二选一

条件运算符也叫三元运算符，符号是问号和冒号，格式一句话：

条件 ? 值甲 : 值乙

意思是：条件为真就取值甲，条件为假就取值乙。

三、位运算符：直接摆弄二进制

这是本片的重头戏。位运算不关心数字是几，而是直接操作它底层的二进制 0 和 1。上位机读 PLC、Modbus 的开关状态时，几乎离不开它。

先补一点点二进制基础。一个整数在电脑里是一串 0 和 1，比如数字 5 的二进制是：

从右边数，最右边是第 0 位，往左依次是第 1 位、第 2 位……每一位只有 0 或 1 两种状态。5 的二进制里，第 0 位和第 2 位是 1，其余是 0。

位运算符有六个，但新手先掌握四个就够：

  • 与（&）：两位都是 1，结果才是 1。
  • 或（|）：两位只要有一个 1，结果就是 1。
  • 左移（<<）：整体往左挪，空位补 0，相当于乘 2。
  • 右移（>>）：整体往右挪，相当于除以 2。

3.1 用「与」读某一位

与运算（&）最常见的用法是：读一个整数里某一位是 0 还是 1。上位机里，一个字节的 8 个位，常常就代表 8 个开关的状态。
为什么 1、2、4、8 能对应每一位？

因为这几个数正好是 2 的 0、1、2、3 次方，二进制里只有一位是 1，其余全是 0：

数字二进制
10000 0001
20000 0010
40000 0100
80000 1000

用它们去「与」state，等于只把某一位单独抠出来看。这一位是 1，结果就不是 0，开关就是开；是 0，结果就是 0，开关就是关。

3.2 用「或」打开某一位

或运算（|）的常见用法是：把某一位设置成 1（打开开关）。

「或」能把某位打开，「与」能读某位是开是关。一开一读，就是上位机控制开关量的核心手法。

3.3 用「左移」「右移」快速乘除

左移（<<）和 右移（>>）能快速乘 2 或除 2，也常用来生成位掩码。

1 << 3 这个写法在上位机里特别常见，它生成一个「第 3 位是 1」的掩码，等价于写数字 8，但比 8 更直观地表达了「第 3 位」这个意思。

四、逻辑 和 位运算 的区别

新手最容易把 && 和 &、|| 和 | 搞混。它们长得像，但完全是两回事。

符号 名字 结果类型 用途
&& 逻辑与 bool 判断真假，两个条件都满足
& 位与 整数 操作二进制位
` ` 逻辑或 bool 判断真假，满足一个就行
` ` 位或 整数 操作二进制位

一句话记死：判断真假用 &&、||，摆弄二进制用 &、|。用错了要么报错，要么结果完全不对。

六、小结

这一篇我们学了三类运算符：

  • 逻辑运算符：&&（与）、||（或）、!（非），用来判断真假。
  • 条件运算符：?:，一句话二选一。
  • 位运算符：&（位与）、|（位或）、<<（左移）、>>（右移），直接摆弄二进制。

口诀：

判断真假用 &&、||、!；二选一用 ?:；摆弄二进制用 &、|、<<、>>。
