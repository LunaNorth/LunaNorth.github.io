完成本节后，你要能够：

三种常见模式：

模式 速度变化
EaseIn 开始慢，后面快
EaseOut 开始快，后面慢
EaseInOut 两端慢，中间快

缓动不会改变起点、终点和总时长，只会改变“什么时候走到哪里”。

1.9 跟做检查点

  • 三条动画同时开始。
  • 三条动画的终点都是 X=520。
  • 三条动画的时长都是 1800ms。

1.10 常见错误

现象 常见原因 修正方法

看不出缓动差异 时长太短 先使用 1500ms 以上
暂停只停一条 分别控制多个 Storyboard 统一放入一个 Storyboard
缓动没有生效 使用了普通 LinearKeyFrame 改为 EasingDoubleKeyFrame
动画结束后跳回 FillBehavior 或基础值问题 检查结束行为
播放叠加 每次播放都创建新时钟 开始前 Stop 旧时钟

动画结束后消失 填充行为或路径坐标问题 检查 FillBehavior 和起点

3. 动画对象的相关速率

3.1 本节目标

完成本节后，你要能够：

  1. 使用 SpeedRatio 改变整体播放速度。
  2. 使用 AccelerationRatio 控制开头加速比例。
  3. 使用 DecelerationRatio 控制结尾减速比例。
  4. 理解加减速比例之和不能超过 1。
  5. 区分“整体速率”和“内部节奏”。

3.2 三个属性分别做什么

图 4：SpeedRatio 改变整体快慢，加减速比例改变时间线内部节奏。

属性 作用
SpeedRatio 整体播放速度倍率
AccelerationRatio 时间线开头用于加速的比例
DecelerationRatio 时间线结尾用于减速的比例

3.9 三种速率属性的选择

需求 选择
整体播放快一点 提高 SpeedRatio
整体播放慢一点 降低 SpeedRatio
开头逐渐加速 设置 AccelerationRatio
结尾逐渐减速 设置 DecelerationRatio
两端慢、中间快 同时设置加减速比例，或使用 Easing

如果只是想让速度曲线自然，EasingFunction 通常更直观。如果希望调整时间线的加速和减速时间占比，再考虑两个 Ratio 属性。

3.10 跟做检查点

  • 三张卡片同时开始。
  • 三张卡片的目标位置相同。
  • 1.50× 最早到达。
  • 0.65× 最后到达。
  • 暂停时三条时间线一起停住。
  • 继续后按各自速度继续。
  • 知道 SpeedRatio 与加减速比例的区别。

3.11 常见错误

现象 常见原因 修正方法
速率没有区别 所有动画 SpeedRatio 都是 1 设置不同倍率
动画不开始 SpeedRatio 为 0 或负数 使用大于 0 的值
加速比例设置失败 两个比例之和超过 1 重新分配比例
和缓动混淆 把 Ratio 当成 Easing 区分整体倍率与内部速度曲线
暂停后位置跳动 重置了基础值 检查暂停逻辑
播放叠加 每次播放没有停止旧时钟 先 Stop 再 Begin

4. 动画对象的执行累加计算

4.1 本节目标

  1. 理解动画值、基础值和最终结果的关系。
  2. 使用 IsAdditive 把动画结果叠加到基础值。
  3. 使用 IsCumulative 让重复轮次继续累加。
  4. 区分“加法”和“累计”。
  5. 正确计算重复播放后的最终值。

4.4 IsAdditive

IsAdditive=true 表示动画值要叠加到基础值上，而不是直接替换基础值。

一轮结束仍然得到：

IsAdditive 的关键是“在基础值上再加动画输出”。本例重复播放时，每一轮仍只叠加一次单轮结果，所以最终停在 110。

4.12 跟做检查点

  • 三条动画都使用相同的基础值和单轮目标。
  • 普通重复结束后不会无限增大。
  • IsAdditive 的结果与普通结果可以比较。

  • 重置后回到基础值。
  • 能说清动画值、基础值和最终值。

4.13 常见错误

现象 常见原因 修正方法
重复后越走越远 IsCumulative=true 明确是否需要累计
IsAdditive 看不出区别 只播放一轮 增加重复或后续动画对比
最终值计算错误 基础值和动画值混在一起 分开记录
普通动画误加基础值 把动画输出当成了 Additive 普通结果直接使用动画输出
重置后位置错误 没有恢复基础 X 重置基础值
动画越来越快 每轮都创建新时钟 复用同一 Storyboard
暂停后累计丢失 重置了时间线或基础值 只 Pause，不要 Stop

缓动关键帧

问题 优先检查
看不出缓动 时长是否太短
缓动无效 是否使用普通关键帧

重置不完整 是否恢复所有变换值

路径动画

问题 优先检查
只走一个方向 是否只创建 X 或 Y
轨迹偏移 两条时间线参数是否一致
路径资源找不到 Key 是否匹配
目标属性错误 是否指向 TranslateTransform
重置不完整 X、Y 是否都恢复

速率

问题 优先检查
速度没有变化 SpeedRatio 是否相同
动画不开始 SpeedRatio 是否大于 0
比例设置失败 两个 Ratio 之和是否超过 1
和缓动混淆 是否把 Ratio 当 Easing
暂停跳动 是否错误重置基础值

累加

问题 优先检查
越走越远 IsCumulative 是否开启
加法无效 IsAdditive 是否开启
只播放一轮 RepeatBehavior 是否正确
最终值不对 基础值和动画值是否分开
暂停后丢失 是否调用 Stop 而非 Pause

综合练习

练习一：自然进入卡片
